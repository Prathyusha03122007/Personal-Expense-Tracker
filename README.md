# Personal Expense Tracker with Budget Insights

A Flask web application designed for students to track daily expenses, set monthly budgets, and visualize financial trends. This app features a premium glassmorphism UI, interactive charts, and intelligent budget warnings.

## Features Built for the Demo

1.  **Auth Module:** Secure signup and login with hashed passwords.
2.  **Transaction Logging:** Floating action button (FAB) for quick expense entry. Instant updates to the dashboard and budget progress.
3.  **Budget System:** Set monthly budgets per category. Visual progress bars on the dashboard turn warning (yellow) at 80% and danger (red) at 100%.
4.  **Insights Module:** 
    *   Category Split (Pie Chart)
    *   Daily Spend Trend (Line Chart)
    *   Budget vs Actual (Bar Chart)
5.  **Export Module:** One-click CSV export of all transactions.
6.  **Responsive Design:** Fully mobile-first, designed to look stunning on phones.

## Setup & Run Instructions

1.  **Create and Activate Virtual Environment (Windows):**
    ```powershell
    python -m venv venv
    .\venv\Scripts\activate
    ```

2.  **Install Dependencies:**
    ```powershell
    pip install -r requirements.txt
    ```

3.  **Seed the Database (3 Months of Demo Data):**
    ```powershell
    python seed.py
    ```
    *This generates random expenses, income, and budgets for the last 3 months to populate the charts beautifully.*

4.  **Run the App:**
    ```powershell
    python app.py
    ```

5.  **Access:**
    Open your browser and navigate to `http://127.0.0.1:5000`
